# Журнал ресёрча: хостинг без VPN

## Исходное состояние

- Сайт на Vercel (`family-app-pearl-three.vercel.app`), бэкенд Supabase Cloud (`pbipnjlsxkbhdyfebdeo.supabase.co`).
- Ресёрч 13.10 (`docs/research/2026-10-13-tech-risks.md`): API Supabase за Cloudflare, провайдеры режут Cloudflare после ~16 КБ; запасной хостинг фронта — Yandex Object Storage.
- 15.10 на телефоне владельца сайт открылся, но рецепты и синхронизация не загрузились; с ПК всё работает. Результатов `/probe` с телефонов нет.

**Метрика:** число вариантов, по которым известны все пять фактов: цена для нашей нагрузки, HTTPS, отдача `index.html` на любой путь, способ деплоя, оплата российской картой.
**Направление:** больше.

## Что видно по коду

- Адрес базы задаёт одна переменная `VITE_SUPABASE_URL` (`app/src/lib/supabase.ts`). Смена адреса на прокси — правка переменной и пересборка.
- Ключ сессии в браузере строится из первого слова домена базы (`AUTH_STORAGE_KEY`). При смене домена все выйдут из аккаунта и войдут заново один раз.
- Клиент пользуется REST, Realtime (`.channel`), Storage (фото), Edge Functions. Прокси обязан пропускать WebSocket.
- Вход через Google возвращает браузер на `<ref>.supabase.co/auth/v1/callback`, мимо прокси.
- `/probe` уже проверяет ответ 64 КБ и показывает, сколько байт дошло. Готовый тест для любого варианта.

## Итерация 1 — 2026-10-18

Два параллельных поиска:
- `raw/frontend-hosting.md` — российский хостинг для статики;
- `raw/backend-access.md` — доступ к Supabase из РФ, прокси, свой Supabase, цены VPS.

**Нашли:**
- Сайт: 11 вариантов, у 5 известны все пять фактов (Yandex Object Storage, Timeweb App Platform, Timeweb S3, Amvera, GitVerse Pages). Отсеяны SourceCraft (нет service worker), VK Cloud (нет HTTPS), Beget (HTTPS не подтверждён).
- База: ограничение Cloudflare не снято, сентябрьские обрывы Vercel на 10–20 КБ; блокировок supabase.co в РФ не найдено. Свой домен Supabase не помогает (CNAME на те же адреса Cloudflare).
- Цены VPS у 7 провайдеров, домен .ru у 3 регистраторов.

**Пусто:**
- замеров «VPS в РФ → Cloudflare, ответ больше 16 КБ» нет; отчётов о прокси к Supabase из РФ нет;
- OONI и Cloudflare Radar за 2026 по Cloudflare или supabase.co нет;
- отчётов, открываются ли сайты на российских хостингах при белых списках, нет;
- код ответа страницы ошибки в Yandex Object Storage не описан.

**Метрика:** 0 → 5 вариантов сайта с полным набором фактов, плюс 2 варианта для базы с ценой и списком работ.

Вторая итерация не нужна: оставшийся главный вопрос (режут ли участок РФ → Cloudflare) решается не поиском, а замером с VPS, это шаг 4 плана.
