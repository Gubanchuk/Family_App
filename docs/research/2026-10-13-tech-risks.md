# Технические риски: семья в РФ, без VPN

Ресёрч субагента от 13.10.2026. Ссылки и даты — из отчёта, вручную не перепроверены. Подтверждённое отделено от единичных сообщений.

## Главное

- Провайдеры режут трафик к Cloudflare: с 09.06.2025 от сайтов за Cloudflare приходят только первые ~16 КБ ответа ([blog.cloudflare.com, 26.06.2025](https://blog.cloudflare.com/russian-internet-users-are-unable-to-access-the-open-internet/)). Подтверждений, что ограничение сняли, нет.
- В 68–71 регионе на мобильном интернете действуют «белые списки» ([ru.wikipedia](https://ru.wikipedia.org/wiki/«Белые_списки»_сайтов_в_России), на 12.03.2026). Пока список включён, частное приложение не открывается ни с какого хостинга. Домашний проводной интернет не затронут (опровержение Минцифры от 23.03.2026).

## Supabase

- API проекта `<ref>.supabase.co` обслуживает Cloudflare (заголовки `Server: cloudflare`, `CF-RAY`). Значит, на него распространяется ограничение в 16 КБ.
- В реестре РКН supabase.co нет.
- Отзывы противоречат друг другу: «вечный pending без VPN» и «всё работает» ([Хабр, 05.2025](https://habr.com/ru/articles/904840/comments/)), из Мурманска доступен ([Vercel community, 26.09.2026](https://community.vercel.com/t/regional-access-to-vercel-app-varies-by-ingress-ip-from-russia/49777)).
- Обходы:
  - свой домен — $10/мес поверх Pro за $25, поможет ли — неизвестно;
  - nginx-прокси на российском VPS — Timeweb 1 ГБ, 1 380 ₽/мес;
  - Supabase на своём сервере — от 4 ГБ RAM (Timeweb MSK 50, 3 840 ₽/мес), бэкапы и обновления на нас;
  - PocketBase — один бинарник на SQLite, есть вход по коду на почту, версия 0.40.5, до 1.0.
- Бесплатный тариф: база 500 МБ, хранилище 1 ГБ, 500 тыс. вызовов Edge Functions, бэкапов нет. Проект встаёт на паузу после 7 дней низкой активности.

## Хостинг фронта

- Vercel: жалобы 29.10.2025, 08.09.2026 и 26.09.2026, в последней не открывается даже `*.vercel.app`.
- Netlify, Cloudflare Pages — частично под ограничениями.
- GitHub: доля неудачных подключений выросла с 4% до 16% с 05.05.2026 (OONI, [Хабр 15.06.2026](https://habr.com/ru/articles/1047444/)).
- Yandex Object Storage: статика из бакета, бесплатно 1 ГБ хранения, 100 тыс. GET и 100 ГБ трафика в месяц ([тарифы](https://yandex.cloud/ru/docs/storage/pricing)).

## Вход через Google

- С 07.07.2026 действует 199-ФЗ (ст. 13.55 КоАП): владельцам ресурсов запрещено авторизовать пользователей из РФ через иностранные сервисы, штраф для гражданина 10–20 тыс. ₽ ([ppt.ru](https://ppt.ru/news/shtrafi/shtrafy-za-avtorizatsiyu-cherez-inostrannye-servisy-vstupayut-v-silu-s-7-iyulya), [garant.ru](https://www.garant.ru/article/2136195/)). Касается ли закон закрытого семейного приложения, разбора нет.
- Google открывается, но были сбои: 23–24.04.2026 и 14.07.2026.
- Что предлагает Supabase вместо Google:
  - ссылка или код на почту (Яндекс, Mail.ru) — работает из коробки;
  - SMS через свой шлюз (Send SMS Hook);
  - свои OAuth-провайдеры с 08.04.2026, на бесплатном тарифе до трёх. Яндекс ID подходит, но совместимость с заголовком `Authorization: OAuth` не проверена.

## Web Push

- iOS 16.4+, только после «На экран Домой», разрешение по нажатию ([WebKit](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)).
- Android Chrome работает через `fcm.googleapis.com`. Блокировок FCM и APNs не найдено.
- При «белых списках» пуши не доходят.
- Пуши по расписанию: pg_cron + pg_net + Edge Function ([документация](https://supabase.com/docs/guides/functions/schedule-functions)). Библиотека `web-push` в edge-среде падает на `createECDH`, нужна реализация на Web Crypto.

## PWA → Capacitor

React-код и клиент базы переносятся без изменений. Пуши меняются на `@capacitor/push-notifications` (FCM и APNs, отдельная ветка отправки на сервере). Для входа нужна URL-схема в списке разрешённых адресов возврата.

## Что из этого следует для проекта

1. Фронт размещать не на Vercel: Yandex Object Storage или российский VPS.
2. Входить по коду на почту или через Яндекс ID, без Google.
3. Supabase Cloud брать только после проверки с телефона каждого члена семьи (мобильный интернет и Wi-Fi): ответ API больше 16 КБ должен приходить целиком. Если не приходит — свой бэкенд на российском VPS.
4. Приложение должно работать офлайн: данные хранятся локально и синхронизируются, как только появится сеть. Важные напоминания показываются в самом приложении, а не только пушем.
