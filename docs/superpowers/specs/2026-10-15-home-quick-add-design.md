# Главная: «Добавить», плитки по макету; покупки не только еды

Черновик от 15.10.2026, по макету (`mockups/v-cards.js`: `tiles`, `home`; `mockups/data.js`: отдел «Для дома»). Владелец просил не ждать согласования.

## «Добавить» на Главной

- В шапке Главной кнопка «Добавить». Она открывает лист «Что добавить»:
  - «В покупки»;
  - «Попросить» — когда есть Доска;
  - «Хотелку» — когда есть Доска;
  - «Расход» — только родителям и когда есть Деньги.
- Каждый пункт открывает нужный раздел сразу с формой добавления. После сохранения человек видит запись на своём месте.
- Отдельных «дел себе» нет: просьба уходит другому члену семьи. В макете «дело» — это просьба, которую получил я.

## Покупки не только еды

- Позиция, которой нет в словаре продуктов, раскладывается по словам:
  - средство, порошок, мыло, бумага, салфетки, губки и т. п. → «Для дома»;
  - таблетки, сироп, пластырь, витамины и т. п. → «Аптека»;
  - носки, колготки, футболка, кроссовки и т. п. → «Одежда и обувь».
- Не угадалось — «Другое».
- В форме видно, в какой отдел ляжет позиция, и отдел можно сменить одним тапом.
- Отдел «Аптека» стоит в списке после «Для дома».

## Плитки по макету

- «Цель»:
  - сверху название цели;
  - крупно отложенная сумма;
  - полоска прогресса;
  - внизу «из N ₽».
- «Хотелки» у ребёнка: крупно название своей хотелки, внизу «в копилке N ₽».
- «Скоро платить» у родителя: «Название · сумма», внизу когда.
- Раскладка в две колонки без дыр:
  - цель и ещё две плитки: цель высокая слева;
  - цель и одна плитка: обе в ряд;
  - без цели: Покупки на всю ширину, если других плиток нет.

## Проверки

- Модульные:
  - угадывание отдела по словам;
  - смена отдела в форме;
  - лист «Что добавить» показывает только доступные пункты;
  - каждый пункт ведёт на форму;
  - раскладка плиток без дыр.
- Глазами: Главная родителя и ребёнка, лист «Что добавить», форма покупки, днём и ночью.

## Не делаем сейчас

Счётчик дел под именем в ряду «Семья». Под именем сейчас стоит «мама/сын» по просьбе владельца; счётчик добавим, когда решим, как уместить оба.
