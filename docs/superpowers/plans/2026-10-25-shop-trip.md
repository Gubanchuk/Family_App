# Поход в магазин — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** в Покупках появляется «Поход»: общий список на ближайший поход с товарами в нормальных единицах, ценой строки и итогом; в магазине — чек-лист с «в корзине / осталось»; новый товар заводится один раз и предлагается потом.

**Architecture:** одна колонка `shopping_items.in_trip` (миграция, проба `tripList`). Единицы продажи — `content/shop-units.json` и чистый модуль `features/shop/units.ts`. Каталог товаров — словарь + товары семьи, выведенные из прошлых строк (`catalog.ts`), без новой таблицы. Действия — `tripActions.ts`. Экран — `TripView.tsx` с двумя режимами (сборка и магазин), выбор товара — `ProductPicker.tsx` для обоих видов.

**Tech Stack:** React 19, TypeScript, Dexie + outbox, Supabase/PostgREST, PGlite, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-shop-trip-design.md`

## Global Constraints

- Пока миграции нет на сервере (нет `tripList` в `meta.features`), Покупки работают как сейчас: без «Похода», с нынешним «Иду в магазин» и листом «Что берём»; `in_trip` не уходит на сервер.
- Строка одна: строка похода — строка общего списка. Отметка «в корзине» — та же `shopping_marks.bought`.
- Строка продукта словаря хранит количество в единице словаря (г, мл, шт). Свой товар — `г` (выбрали кг), `мл` (выбрали л), `шт`, `уп`. `qty_text` пишется всегда (для старых телефонов и «Скопировать»).
- Цена строки `est_price` = количество × цена за единицу, округлённая до рубля; `price_real` после покупки важнее.
- Шаг степпера — по `shop-units.json`; минус не опускает ниже одного шага (убрать — в листе строки).
- Пока кто-то в магазине, новая ручная строка, «закончилось дома» и «надо купить» с доски получают `in_trip = true`.
- Пересборка списка меню не сбрасывает `in_trip` и не теряет поправленное количество открытой строки, пока меню не поменялось.
- Комментарии в коде — короткий нейтральный английский, как в соседнем коде. Тексты — по-русски, в тоне приложения.
- Коммиты — conventional commits, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `git add <paths>`, никогда `-A`.
- Тесты по папкам (`npx vitest run <paths>` в `app`); полный набор — в конце.

## Review Focus

1. Телефон без миграции: ничего не шлёт с `in_trip`, «Похода» не видно, старый поток работает.
2. Два телефона добавляют один товар в поход без сети — после синхронизации две строки допустимы, но количество каждой цело; один телефон прибавляет количество к уже существующей строке — прибавка не теряется.
3. Меню пересобралось, пока строка меню в походе — строка осталась в походе.
4. Итог «в корзине / осталось» сходится с суммой строк, строки без цены считаются отдельно.
5. 360 px: степпер, цена и название в строке не налезают друг на друга, длинное название переносится.

- Тест PGlite: колонка, заполнение, член семьи меняет `in_trip` чужой строки своей семьи, гард купленной строки меню не мешает менять `in_trip`.

### Task S2: Единицы

**Files:** Create `app/src/features/shop/units.ts`, `units.test.ts`. Читает `content/shop-units.json` (файл уже собран и проверен в `content/`; если импорт JSON из-за пределов `app/` не работает в dev, разрешить путь в `vite.config.ts` `server.fs.allow`).

- `sellOf(item, vocab)`, `stepOf(product)`, `defaultQty(product)`, `nextQty(qty, step, dir)` (прилипает к сетке шага), `formatAmount(qty, unit, sell?, pieceWeight?)` («300 г», «1,5 кг», «500 мл», «1,5 л», «10 шт», «2 пачки · 400 г», «3 шт» для штучных из граммов, «2 уп.»), `unitPriceLabel(product)` («≈ 45 ₽/кг», «≈ 89 ₽/пачка», «≈ 12 ₽/шт», «≈ 95 ₽/л»), `lineEstimate(qty, pricePerUnit)`.
- Русские формы для каждого слова упаковки из JSON (тест: у каждого `pack` из файла есть формы 1/2/5).

### Task S3: Каталог и поиск

**Files:** Create `app/src/features/shop/catalog.ts`, `catalog.test.ts`.

- `Product = { key, title, item: string | null, unit: 'г'|'мл'|'шт'|'уп', dept, price: number | null /* за единицу */, sell, custom: boolean, uses: number }`.
- `buildCatalog({ vocab, prices, items, marks })`: продукты словаря; свои товары из живых ручных строк с `item = null`, сгруппированные по названию (регистр, «ё», пробелы), берёт последнюю строку с количеством: единицу, цену за единицу (`(price_real ?? est_price) / qty`), отдел. Старые строки только с `qty_text` — свой товар без цены, единица `шт`. `uses` — сколько раз продукт покупали.
- `searchCatalog(catalog, q, limit = 8)`: точное > начало названия > начало слова > основа слова (как `guessIngredient`) > вхождение; при равенстве — `uses`, потом название. `frequent(catalog, n = 8)`.

### Task S4: Действия похода

**Files:** Create `app/src/features/shop/tripActions.ts`, `tripActions.test.ts`; Modify `shopActions.ts` (`addManualItem` ставит `in_trip`, пока поход идёт), `stock.ts` и `features/board/needToShop.ts` (то же), `features/shop/menuList.ts` (пересборка сохраняет `in_trip` и количество открытой строки — проверить и покрыть тестом).

- `addProductLine(db, me, { product?, title, qty, unit, pricePerUnit, dept, inTrip, urgent? }) → id`: если такой товар уже открыт в походе — прибавить количество к той строке (моё решение), иначе новая строка `manual`.
- `setLineQty(db, line, qty, pricePerUnit?)`, `setInTrip(db, lines, on)`, `tripLines(items, marks, trip?)` (сборка: открытые `in_trip`; магазин: ещё купленные во время этого похода), `tripTotals(lines, marks)` → `{ count, total, inCart: { count, sum }, left: { count, sum }, unpriced }`, `endSummary`.
- «Иду в магазин» — `goShopping` без корзины; старые походы с `items` читаются как раньше.

### Task S5: Выбор товара

**Files:** Create `app/src/features/shop/ProductPicker.tsx`, `QtyStepper.tsx`, тесты.

- Лист: поле поиска с фокусом; пусто — «Часто берём»; результаты — название, цена за единицу, отдел; тап — шаг количества (степпер, цена строки, «Добавить»); нет совпадения — «Новый товар «…»»: «Как считаем: кг · шт · л · упаковка», «Цена за 1 кг» (необязательно), отдел (угадан `guessDept`, чипы), количество, «Добавить».
- Используется в «Походе» (в поход) и в «Списке» (в список; в поход — только пока поход идёт). Заменяет `AddItemSheet` при `tripList`.
- `QtyStepper`: «−», значение (тап — ввод числа; кг и л с запятой), «+»; подписи для экранного диктора.
