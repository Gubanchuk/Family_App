# Баланс недели: правила проверки

Шаблоны недель лежат в `content/weeks.json` и проверяются скриптом по этим правилам. Источники норм — `docs/research/2026-10-13-content-sources.md`.

## Формат шаблона

```json
{
  "id": "autumn-1",
  "name": "Осенняя",
  "season": ["autumn"],
  "note": "одна строка: чем неделя отличается",
  "days": [
    {
      "breakfast": "br-syrniki",
      "lunch": { "soup": "sp-borsch", "salad": "sl-kapusta-morkov" },
      "snack": "sn-pechenye-yabloki",
      "dinner": { "main": "mn-kotlety-kurinye", "side": "side-grechka", "salad": null }
    }
  ]
}
```

- В `days` ровно 7 дней, с понедельника.
- Суп повторяется в обеде 2–3 дня подряд — это одна кастрюля.
- `side` — только если у основного блюда непустой `sides`; берётся из этого списка.
- `salad` — по желанию.
- Полдник — id блюда или простой перекус без рецепта: `{ "simple": "Кефир и яблоко", "items": [{ "item": "кефир", "qty": 200 }, { "item": "яблоки", "qty": 150 }] }`. Количества — на одного человека.

## Сколько съедает один человек

Порция блюда — количества рецепта, делённые на `servings`. Считаем на одного взрослого. Дима получает половину того же, отдельно его не считаем.

## Правила

| Что | Норма на человека в неделю | Откуда |
|---|---|---|
| Рыба | не реже 2 раз (рыбный ужин или рыбный суп, суп — один раз на кастрюлю) | Программа питания детей 1–3 лет, с. 20 |
| Рыба, граммы | от 400 г на взрослую порцию: Диме по Программе около 200 г, он ест половину порции | Программа, с. 20 |
| Мясо, птица или рыба | каждый день от 40 г на порцию; в рыбный день рыба заменяет мясо | Программа, с. 18–20: «каждый день мясо или птица» |
| Птица и красное мясо | птицы по весу больше красного мяса, но не больше чем вдвое; ориентир 1,4 | Приказ Минздрава № 614: 770 г птицы и 560 г красного мяса |
| Молочное | каждый день хотя бы в двух приёмах пищи от 30 г на порцию; третий раз — кефир перед сном, вне меню | Программа, с. 18–20: «молочное трижды в день» |
| Овощи и фрукты без картофеля | от 2,8 кг (400 г в день) | ВОЗ |
| Яйца | от 3 шт, считая яйца внутри блюд | Приказ № 614: 5 шт |
| Творог | от 200 г | Программа: 200–250 г ребёнку; приказ № 614: ~310 г |
| Бобовые для Димы | блюд с `protein: legume` не больше 3 | Программа, с. 21 |
| Сладкое для Димы | блюд `dessert` и сладкой выпечки не больше 3 | Программа, с. 22 |
| Повторы | одно и то же второе блюдо не чаще 1 раза за неделю, кроме супа | правило семьи: второе готовят свежее |
| Будни | ужин понедельник–пятница с тегом `будни` или `быстро` | правило семьи: в будни быстро |
| «Не едим» | ни одного блюда с грибами и печенью | правило семьи |

Скрипт выводит по каждому шаблону таблицу «норма / получилось» и список нарушений. Шаблон с нарушениями в базу не идёт.
