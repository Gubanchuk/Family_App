# Формат базы рецептов

Рецепты лежат в `content/recipes/*.json`, словарь продуктов — в `content/ingredients.json`. Из этих файлов собирается начальная база приложения.

## Семья и порции

- Готовим на двух взрослых, сына 11 лет и Диму 2 лет. Сын ест как взрослый, Дима — половину, обычное блюдо считаем на 4 порции.
- Количества в рецепте даны на `servings` порций.
- Суп варим кастрюлей на 2–3 дня: `servings` 10–12, `keepsDays` 3.
- Не едим: грибы, печень. В рецептах их нет.
- Продукты — из обычного супермаркета (Пятёрочка, Магнит, Перекрёсток).

## Рецепт

| Поле | Что это |
|---|---|
| `id` | латиница через дефис с префиксом раздела: `br-syrniki` |
| `name` | название, как его скажет мама: «Сырники» |
| `about` | одна строка до 80 знаков: чем блюдо хорошо |
| `category` | `breakfast`, `soup`, `main`, `side`, `salad`, `snack`, `dessert`, `drink` |
| `meals` | в какие приёмы пищи подходит: `breakfast`, `lunch`, `snack`, `dinner` |
| `time` | `{ "active": 20, "total": 35 }`, минуты |
| `servings` | на сколько порций даны количества |
| `keepsDays` | сколько дней блюдо нормально стоит в холодильнике |
| `protein` | главный белок: `poultry`, `red-meat`, `fish`, `egg`, `cottage`, `dairy`, `legume`, `none` |
| `sides` | для `main` без гарнира — id подходящих гарниров; у блюда с гарниром — `[]` |
| `tags` | из списка ниже |
| `season` | `"any"` или список: `winter`, `spring`, `summer`, `autumn` |
| `ingredients` | продукты, см. ниже |
| `steps` | 3–8 коротких шагов своими словами |
| `dima` | `{ "level": "ok" \| "adapt" \| "skip", "note": "..." }` |
| `source` | `{ "url": "...", "site": "..." }` — страница, которую открыли и по которой сверили пропорции |
| `collections` | только у раздела «Что покушать», см. ниже |

Префиксы `id`: `br-` завтрак, `sn-` полдник, `dr-` напиток, `ds-` десерт, `sp-` суп, `sl-` салат, `mn-` основное, `side-` гарнир, `ex-` «Что покушать».

### Продукт в рецепте

```json
{ "item": "морковь", "qty": 150, "note": "крупно", "optional": false }
```

- `item` — точное имя из `content/ingredients.json`. Нужного продукта в словаре нет — добавь его в `newIngredients` своего файла.
- `qty` — в единице продукта из словаря: г, мл или шт. Штучные овощи переводим в граммы по `pieceWeight`: луковица — 100 г.
- Соль и специи: `"qty": null, "toTaste": true`.

### Теги

`быстро` — всё блюдо до 30 минут; `будни` — до 45 минут, из них активных до 30; `выходные`; `на 2–3 дня`; `постное`; `бюджетное`; `праздничное`; `духовка`; `мультиварка`; `без плиты`; `детское` — дети едят охотно.

### Дима, 2 года

Правила — в `docs/research/2026-10-13-content-sources.md`, раздел «Малыш 2 лет».

- `ok` — ест то же, что все.
- `adapt` — ест с поправкой. В `note` — что сделать: «отложить порцию до соли», «котлеты на пару», «рыбу без костей».
- `skip` — не давать. В `note` — чем заменить.

|---|---|
| `side-grechka` | Гречка |
| `side-ris` | Рис |
| `side-pyure` | Картофельное пюре |
| `side-kartofel-otvarnoy` | Картофель отварной с укропом |
| `side-kartofel-zapechenny` | Картофель, запечённый дольками |
| `side-makarony` | Макароны |
| `side-bulgur` | Булгур |
| `side-perlovka` | Перловка |
| `side-kapusta-tushenaya` | Тушёная капуста |

### «Что покушать»

Блюда для разнообразия поверх недели. `collections` — одна или несколько подборок:

`weekend` «Выходной проект», `world` «Кухни мира», `cafe` «Как в кафе», `quick-new` «Быстро и необычно», `sweet` «Сладкое», `kids-cook` «Готовим с детьми».

## Файл раздела

```json
{
  "section": "Завтраки, полдники, напитки",
  "recipes": [],
  "newIngredients": [{ "item": "...", "unit": "г", "dept": "...", "group": "...", "pieceWeight": null, "pantry": false }]
}
```

## Словарь продуктов

Поля: `item`, `unit` (г, мл, шт), `dept` — отдел магазина, `group` — группа для баланса недели, `pieceWeight` — вес одной штуки в граммах, `pieceName` — как называть штуку, если не «шт», `pantry` — всегда есть дома, в список покупок не попадает.

Отделы: Овощи и фрукты, Мясо и птица, Рыба, Молочное и яйца, Бакалея, Хлеб, Заморозка, Консервы и соусы, Специи.

Группы: `potato`, `veg`, `fruit`, `cereal`, `bread`, `legume`, `poultry`, `red-meat`, `fish`, `seafood`, `processed`, `egg`, `dairy`, `cottage`, `cheese`, `fat`, `sugar`, `sweets`, `nuts`, `sauce`, `spice`, `other`.
